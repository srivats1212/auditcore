# First paid LLM tagging run, 2026-10-23

Stage-2 tagging (`auditcore process --llm --llm-max 20`) on a fresh local
corpus, with the default model `claude-sonnet-5-5` at effort `medium` and the
prompt as of commit 66cc5d1 (taxonomy 1.1, paper-only flag, validation-scope
and 211.68 lines, request-tail trim). Each proposed tag below was read against
the citation text. **These are not gold labels**, and no tag in the review
queue was accepted or rejected. That stays with the human reviewer.

## Corpus

| Step | Result |
|---|---|
| `ingest wl --subject CGMP --max-rows 1500 --limit 120` | 1,500 listing rows, 454 matched, 120 letters fetched, 3 errors |
| `ingest 483 --max-rows 60 --limit 25` | 58 entries, 25 PDFs downloaded, 0 errors |
| `process` (rules only) | 143 documents, 519 observations, 728 citations, 27 rule tags |

Citation IDs below refer to this corpus. They are not the IDs in
`tagging-preview-2026-10-23.md`, because the corpus was re-ingested.

Where the money went: uncached input $0.039, cache reads $0.033, cache write
$0.022, output $0.006. Output was about 28 tokens per call, so at effort
`medium` the model did almost no visible reasoning on these citations. The
taxonomy prefix is a fixed 8,648 tokens per call and is a third of the cost
even when cached.

**Extrapolation to the whole corpus.** The 20 citations sent about 60,000
characters (about 3.1 characters per input token). All 728 citations send
1.68 million characters after the request-tail trim, which works out to about
$2.60 for a full run at today's prices. The corpus has only 648 distinct
citation texts (a violation cited under two CFR sections becomes two
citations with the same text); tagging each distinct text once would cut that
to about $2.20. Output on citations that are
actually about computerized systems may run longer than on this sample.

## Sample caveat

`--llm-max` takes citations in document order, so the 20 came from the first
five warning letters (two aseptic drug manufacturers, an OTC manufacturer, an
OTC cosmetics firm and a device manufacturer). No 483 observation was tagged,
none of the 20 cites 21 CFR 211.68, and only two (11 and 14) mention an
electronic system at all. The run says more about false positives than about recall.

All 15 look right to leave untagged under the current taxonomy, with two
possible misses:

- **9, [Baxter, violation 4](https://www.fda.gov/inspections-compliance-enforcement-and-criminal-investigations/warning-letters/baxter-international-inc-733231-09292026).**
  Sterility test records were signed as showing container integrity verified;

- **11, CS-LAB-005.** "You routinely invalidated failing batch release results

## The rules under test

- **Validation scope: held.** Eight citations used validation language about
  things that are not software: aseptic and sterilization process validation
  and (b)(4) cycle re-qualification (3, 4, 7), design validation of devices
  (18, 19, 20), and validating the reliability of supplier test results
  (12, 13, 15, 16). No VAL mode fired on any of them.
- **211.68: not exercised.** None of the 20 cites 211.68. The corpus has 3
  such citations; a targeted run on them would test this line.
- **CS modes on non-computerized findings: held.** No CS mode fired on aseptic
  behavior, cross-contamination, visual inspection, identity testing, quality
  unit oversight in general, or device risk management. Citation 19 names an
  "Automated Optical Inspection system" whose failure mode was left out of a
  risk assessment; the model correctly did not treat that as a
  computerized-system finding. Citation 6 says samples were "mistakenly
  discarded"; the model correctly did not tag record destruction (CS-EDC-004),
  since samples are not records.
- **paper_only: held where the medium is stated, split where it is not.** See
  finding 1.

## Comparison with the rules stage

On these 20 citations the rules proposed 3 tags (1, 2, 10). The LLM proposed
the same mode on all 3 and added 2 the rules missed (11, 14). The two stages
disagree only on the paper_only flag for citation 10.

Across the whole corpus the rules proposed 27 tags: CS-DI-005 (8, all
paper_only), CS-LAB-001 (4), CS-DI-003 (3, paper_only), CS-ACC-004 (2),
CS-AUD-002 (2), CS-DI-002 (2, paper_only), CS-LAB-003 (2), and one each of
CS-ACC-002, CS-ACC-007, CS-EDC-004 and CS-VAL-001. 13 of the 27 are
paper_only. None of the non-paper rule hits fell inside this 20-citation
sample, so the LLM was not tested on them.

## Findings

1. **paper_only needs a default for an unstated medium (decision needed).**
   The prompt says to set paper_only true when only paper is involved and
   false when an electronic or hybrid record is involved. It says nothing for
   text that names neither. The rules default to paper (no electronic cue
   means paper_only); the LLM defaulted to electronic on citation 10. Under
   the counting rule this decides whether a finding counts as
   computerized-systems enforcement. Options: (a) tell the model to set
   paper_only true unless an electronic record is stated, matching the rules
   and the conservative counting rule; (b) add a third value, "unstated", and
   keep it out of counts until a reviewer decides. Recommendation: (a), since
   it matches the rules and keeps headline numbers conservative.
2. **Sibling citations are tagged twice.** A violation cited under two CFR
   sections becomes two citations with identical text, and each gets its own
   LLM call: 4 of the 20 calls here (citations 2, 4, 13, 16), and 80 of 728
   corpus-wide (11 percent). The two calls also return different evidence
   spans for the same text. Since a review decision already applies to all
   siblings with the same text, the tagger could call once per distinct text
   and copy the tags.
3. **Passing mentions are still open (prompt change 4).** Citation 14 is the
   first live example. Decide whether a one-line item in a quality-unit list
   ("adequate review of ... audit trails") is taggable.
4. **The next run needs a better sample.** Document-order selection spent
   this run on aseptic and device letters. A run on the 27 rule-hit
   citations, the 3 citations under 211.68 and a few 483 observations would
   test recall, the 211.68 line and OCR text, for about $0.15 at today's
   rate. That needs a way to pick citations (for example a `--citation-ids`
   option) and your go-ahead.
